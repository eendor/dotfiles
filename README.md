# Dotfiles

Shell and desktop configuration for my Linux setup: Bash, Zsh, Hyprland,
Waybar, Kitty, Mako, Rofi, Wofi, Fastfetch, Cava, and Fontconfig.

Files mirror their paths under the home directory. Review and copy only the
configs you need, and back up your existing files first. Some settings
reference machine-specific paths, fonts, or scripts not included here.
